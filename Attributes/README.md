# Attributes

## Задание

Создать приложение с одним EditText и шестью кнопками. Кнопки должны переключать цвет текста между чёрным и красным, размер текста — между 8 и 24 sp, фон поля — между белым и жёлтым. Изменения выполнять через соответствующие set-методы.

## Выполнено

В XML-разметке размещены поле ввода и три ряда по две кнопки. В MainActivity для каждой кнопки установлен отдельный обработчик нажатия.

Цвет текста изменяется через setTextColor(), размер — через setTextSize() с единицей измерения sp, фон поля — через setBackgroundColor(). При изменении оформления введённый текст сохраняется. Строки, цвета и размеры вынесены в ресурсы проекта.
