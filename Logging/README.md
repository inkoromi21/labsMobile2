# Logging

## Задание

Создать приложение с пустым EditText и двумя кнопками: button_log с текстом «Логирование Log» и button_timber с текстом «Логирование Timber».

Первая кнопка должна записывать текст из поля через Log с уровнем verbose и тегом From EditText. Вторая — через Timber с уровнем verbose без вручную заданного тега. Подключить библиотеку Timber и инициализировать её через Timber.plant(Timber.DebugTree()).

## Выполнено

В XML-разметке размещены поле ввода и две кнопки. В MainActivity установлены обработчики, которые считывают текущий текст из EditText. Первая кнопка вызывает Log.v() с тегом From EditText, вторая — Timber.v() с автоматически определённым тегом MainActivity.

Подключена библиотека Timber версии 5.0.1. DebugTree инициализируется в onCreate(); проверка количества деревьев предотвращает повторную инициализацию. Введённый текст передаётся в Timber как аргумент формата, чтобы корректно записывать символы процента.
