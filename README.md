# Лабораторная работа № 2

Тема: события в приложении.

Автор: Воробьев Семен Евгеньевич.

## Задание

Создать три Android-приложения на Kotlin:

1. ToastHandler — вывод короткого уведомления «Кнопка ОК» при нажатии кнопки «ОК».
2. Logging — запись текста из EditText через Log и Timber с уровнем verbose.
3. Attributes — изменение цвета текста, размера текста и фона EditText с помощью шести кнопок.

## Выполнено

Созданы три отдельных приложения на Kotlin с XML-разметкой. Элементы интерфейса найдены через findViewById(), для кнопок установлены обработчики нажатия.

В ToastHandler реализован вывод Toast. В Logging подключён Timber и реализованы оба способа логирования. В Attributes реализовано переключение цвета текста, размера текста и фона поля ввода.
