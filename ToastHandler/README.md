# ToastHandler

## Задание

Создать приложение с вертикальным LinearLayout и кнопкой «ОК» с идентификатором button_ok. Найти кнопку через findViewById() и установить обработчик нажатия, который показывает короткое уведомление «Кнопка ОК».

## Выполнено

В XML-разметке создан вертикальный LinearLayout с кнопкой button_ok. В MainActivity кнопка найдена через findViewById(), для неё установлен обработчик setOnClickListener. При нажатии вызывается Toast.makeText() с текстом «Кнопка ОК» и длительностью Toast.LENGTH_SHORT, затем уведомление выводится методом show().
